AutoBrightness now has a native C#/.NET Windows app that uses one webcam to adjust a laptop panel and compatible external monitors, with independent brightness preferences.

## Download and run

Download **AutoBrightness-v2.3.0-win-x64.zip**, extract it, and run **AutoBrightness.exe**. Requires Windows 10 version 2004 or later on x64. No Python or separate .NET installation is needed. The ZIP includes setup instructions, these release notes and the hardware test report. `SHA256SUMS.txt` contains the ZIP checksum.

## Included in this release

- Laptop brightness through WMI and supported external monitors through DDC/CI, including compatible HDMI and USB-C display connections.
- Independent sliders, room references and automatic brightness limits for each screen.
- Verified manual webcam exposure, defaulting to 31.25 ms (+2 stops compared with the previous 7.81 ms ACER setting).
- A 25-region median light meter, temporal noise filtering and gradual brightness changes targeting 1–3 seconds.
- Valid dark scenes keep automatic mode active, with a clear camera-on status.
- Manual adjustments teach one display a new preference without stopping the other.
- Tray operation, remembered automatic mode, camera release on pause/quit, and implemented suspend/reconnect recovery.
- Numeric diagnostics and a built-in monitor readback/restore test. No camera images, audio or analytics are recorded.
- Updated README with screenshots of the actual app; original Python code retained for reference.

## Tested

33 deterministic tests pass. Real laptop WMI and MSI MAG 27CQ6F DDC/CI brightness/readback/restore tests pass. The EXE was exercised through its Windows interface, and the ACER camera accepted a verified exposure lock at 31.25 ms.

## Known limitations

The ACER webcam returned near-black frames during part of testing, then later reported about 118/255 at the same fixed exposure without a restart. Automatic mode stayed active and both displays reacted. Physical lighting was not controlled, so the earlier near-black signal and improved low-light sensitivity are not fully explained. See the included test report for details.

A webcam is not a calibrated ambient-light sensor. Large scene changes, screen reflections and camera processing can affect readings. Higher exposure can clip bright rooms. DDC/CI depends on the monitor, connection and driver; not every dock, adapter or HDR mode supports it. Battery impact and long-term sleep/hotplug behavior remain unverified. Camera access is exclusive, so pause before video calls.

## Upgrading earlier local Windows builds

Quit the previous app before opening this version. Existing limits and display participation are retained. The old default exposure upgrades to 31.25 ms, while custom exposure settings remain unchanged. Room references are recreated once for the new meter using actual screen brightness. Later starts retain those references. You can use **Use these levels for this room** to recalibrate after repositioning the webcam.
